# Sprint 4 Blueprint — Goals, Streaks & Badges

Readr v2.4

Objective:
Add motivation systems on top of the stats foundation using server-derived engagement read models.

---

# Sprint 4 Goal

- Reading goals implemented
- Streak system implemented
- Badge progression implemented
- Engagement surfaces render from API truth
- Progress surfaces are accessible and consistent

---

# Scope

## Goals

- Yearly books goal
- Yearly pages goal
- Optional monthly books goal
- Goal progress summaries
- Empty-state-safe goal responses

---

## Streaks

- Consecutive reading-day tracking
- Reset rules
- Current streak display
- Longest streak display
- Optional grace window flag support
- Stable streak calculation across refreshes

---

## Badges

- Total books milestones
- Pages milestones
- Reading streak milestones
- Session consistency milestones
- Fixed initial badge catalog
- Tiered badge presentation and progress display

---

## API / Architecture

- Goal, streak, and badge state computed server-side
- Exposed through read-only API responses
- UI remains presentation-focused
- No duplicate derivation logic in UI
- Engagement data remains scoped to the authenticated user
- Sprint 4 builds on Sprint 3 stats assumptions rather than introducing parallel aggregate logic

---

## Implementation Notes

- Start with shared response contracts before UI wiring
- Implement streak derivation before badge evaluation
- Keep badge thresholds explicit and deterministic
- Prefer one engagement snapshot response for the initial implementation
- Empty and sparse data must return valid renderable responses
- Do not expand Sprint 4 into editable goal configuration unless explicitly added later

---

# Acceptance Criteria

- Goals render from stable server-derived data
- Streaks calculate consistently across refreshes
- Longest and current streak values are deterministic
- Badge progress reflects API truth
- Empty-state engagement responses render safely
- Progress indicators are accessible
- Motivation systems do not violate architectural boundaries
- No client-side business logic becomes the source of truth for goals, streaks, or badges
