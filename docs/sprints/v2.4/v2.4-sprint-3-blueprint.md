# Sprint 3 Blueprint — Stats & Dashboard

Readr v2.4

Objective:
Introduce server-derived reading statistics and dashboard insight surfaces without adding mutation complexity.

---

# Sprint 3 Goal

- Stats exposed via read-only API
- Dashboard summary UI added
- Charts render stable server-derived trend data
- Derived metrics remain consistent and scalable

# Scope

## Summary Statistics

- Total books
- Books finished
- Pages read
- Sessions logged
- Average session length
- Books finished this month
- Pages read this month

---

## Visualizations

- Reading over time
- Pages per month
- Session duration trends
- Format breakdown (optional, if supported cleanly by Sprint 3 aggregate contracts)

---

## Constraints

- Charts are view-only
- No mutation through analytics surfaces
- Aggregation logic computed server-side
- UI consumes stable API summaries only
- Empty and sparse datasets must remain render-safe

---

# Acceptance Criteria

- Stats are derived from API-backed data
- Dashboard cards render correctly
- Charts consume stable read-only responses
- Empty-state and sparse-data rendering are safe
- No regression in books or sessions flows
- Performance remains acceptable with larger datasets
