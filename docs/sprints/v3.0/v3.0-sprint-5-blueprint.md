The following supporting docs were added for Sprint 5:

- `docs/deployment/architecture.md`
- `docs/deployment/troubleshooting-and-recovery.md`

These docs are intended to reduce ambiguity around:

### Release-lock intent

Sprint 5 is intentionally documentation- and release-readiness-focused.

It does **not** introduce major product-surface work or infrastructure migration. The purpose of this sprint is to leave the stack easier to:

- understand
- validate
- ship
- debug
- review as a full-stack project
