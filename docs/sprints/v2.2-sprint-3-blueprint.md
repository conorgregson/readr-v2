# Sprint 3 Blueprint — Sessions API Contract

Readr v2.2

Objective:
Stabilize Sessions API endpoints before migrating frontend persistence.

---

# Sprint 3 Goal

- Sessions CRUD endpoints implemented
- validation schemas aligned
- deterministic sorting preserved

---

# Scope

Endpoints:

GET /api/sessions
POST /api/sessions
PATCH /api/sessions/:id
DELETE /api/sessions/:id

---

## Validation

Session payload must support:

bookId
date
pages
minutes
notes

At least one of pages or minutes should be provided.

---

# Postman Validation

Test cases:

- create session
- update session
- delete session
- filter by book
- filter by date range

---

# Acceptance Criteria

- endpoints verified in Postman
- responses match frontend contract
