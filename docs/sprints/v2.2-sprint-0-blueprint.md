# Sprint 0 Blueprint — Schema & Contract Audit

Readr v2.2

Objective:
Reconcile the v2.0 backend scaffold with the canonical v2.1 frontend domain models before API integration begins.

---

# Sprint 0 Goal

At the end of this sprint:

- Backend schema matches frontend types
- Prisma models reflect the canonical domain
- API contracts are documented
- migration risks are identified
- server structure is stabilized

---
