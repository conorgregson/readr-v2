# Sprint 2 Blueprint — Auth UX & Session Persistence

Readr v2.3

Objective:
Polish authentication experience and make session handling reliable and seamless.

---

# Sprint 2 Goal

- Smooth login/register experience
- Reliable auth restore on reload
- Clear loading and error states

---

# Scope

## Auth UX Improvements

- Form validation feedback
- Error messages:
  - invalid credentials
  - duplicate email
- Loading states for login/register

---

## Session Persistence

- Restore auth via /auth/me on load
- Handle:
  - expired token
  - invalid token
- Fail gracefully → logout

---

## App Gating

- Auth gate in AppShell
- Prevent UI flash before auth resolves
- Loading screen during bootstrap

---

## Token Handling

- Defensive token reads (safe localStorage)
- Prevent crashes in private mode

---

## Edge Cases

- Logout while requests are in flight
- Invalid token → forced logout
- Missing token → redirect to AuthPage

---

# Acceptance Criteria

- No UI flicker on reload
- Auth persists correctly across refresh
- Errors are user-friendly and clear
- Invalid sessions handled safely
