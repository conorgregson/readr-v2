# Sprint 3 Blueprint — Import/Export & Ownership Safety

Readr v2.3

Objective:
Restore import/export functionality with strict ownership guarantees.

---

# Sprint 3 Goal

- Users can safely import/export data
- Imported data is correctly scoped to user
- No cross-user data leakage

---

# Scope

## Export

- Export Books + Sessions as JSON
- Include all necessary fields
- Maintain structure consistency

---

## Import

- Validate payload shape
- Reject malformed data
- Normalize incoming data

---

## Ownership Enforcement

- Override userId on import
- Never trust incoming userId
- Ensure:
  - sessions belong to valid books
  - data integrity maintained

---

## Safety Checks

- Prevent duplicate IDs (or handle gracefully)
- Handle partial imports safely
- Fail fast on invalid structures

---

## UX

- Import success/failure feedback
- Clear error messaging
- Optional confirmation before overwrite

---

# Acceptance Criteria

- Import/export works end-to-end
- No ability to inject foreign user data
- Invalid payloads safely rejected
- Data integrity preserved after import
