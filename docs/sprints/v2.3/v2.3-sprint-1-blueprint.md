# Sprint 1 Blueprint — Auth & Ownership Foundation

Readr v2.3

Objective:
Establish identity, authentication, and strict data ownership across the system.

---

# Sprint 1 Goal

- Users can register and log in
- JWT-based authentication implemented
- All data scoped to authenticated user
- Frontend integrated with auth API

---

# Scope

## Auth Backend

- User model (Prisma)
- Password hashing (bcrypt)
- JWT generation + verification

Endpoints:

- POST /api/auth/register
- POST /api/auth/login
- GET /api/auth/me

---

## Auth Middleware

- requireAuth middleware
- Extract user from JWT
- Attach userId to request

---

## Data Ownership

- Add userId to:
  - Book
  - Session

- Enforce ownership in:
  - books.service
  - sessions.service

- Validate:
  - Cannot access another user’s data
  - Sessions must belong to owned books

---

## Client Integration

- Login/Register UI
- Auth store (zustand)
- Token storage (localStorage)
- API client attaches Authorization header
- Restore auth on app load

---

## Logout Flow

- Clear token
- Reset books store
- Reset sessions store

---

# Acceptance Criteria

- User can register and login
- Auth token issued and persisted
- All API routes protected
- All data scoped by userId
- Logout clears all state
