# Sprint 1 Blueprint — Books API Contract

Readr v2.2

Objective:
Lock the Books API contract and persistence layer before frontend migration.

---

# Sprint 1 Goal

At the end of this sprint:

- Books CRUD endpoints are stable
- validation schemas align with domain types
- Prisma persistence is verified
- Postman tests pass

---

# Scope

Endpoints:

GET /api/books

- POST /api/books
- PATCH /api/books/:id
- DELETE /api/books/:id

---

## Validation

Zod schemas must validate:

- title
- author
- status
- genre
- series
- seriesType
- format
- formatSubtype
- isbn
- plannedMonth

---

## Response Shape

Books responses must include:

- id
- title
- author
- status
- genre
- series
- seriesType
- format
- formatSubtype
- isbn
- plannedMonth
- startedAt
- finishedAt
- createdAt
- updatedAt

---

# Postman Validation

Test cases:

- create book
- update metadata
- change status
- delete book
- invalid payloads
- missing resource

---

# Acceptance Criteria

- Books endpoints function in Postman
- response schemas match frontend expectations
- Prisma writes persist correctly
